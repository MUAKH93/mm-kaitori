# MM Kaitori — WordPress Client Site

Japanese automotive buyback / quote website with custom WordPress theme.

Part of the [`Rovexa Technologies`](../) umbrella workspace.

## Stack

- WordPress 6.x
- Custom PHP theme (`bmt-kaitori`)
- Docker Compose (local dev)
- Contact Form 7 (quote forms)

## Quick Start

```powershell
cd "C:\Users\Muhammad Umair Ayub\dreams-creations\Rovexa Technologies\mm-kaitori"
Copy-Item .env.example .env
docker compose up -d
```

Open **http://localhost:8080**

See [README.md](./README.md) and [LOCAL-SETUP.md](./LOCAL-SETUP.md) for full setup.
